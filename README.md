# Halloween Surprise — GitHub Pages

This folder is a build-free static site designed for a QR-code reveal experience.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `halloween-surprise`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a URL similar to `https://USERNAME.github.io/halloween-surprise/`.

## Create the surprise QR

After the site is published, open:

`https://USERNAME.github.io/halloween-surprise/qr-card.html?url=https%3A%2F%2FUSERNAME.github.io%2Fhalloween-surprise%2F`

The card generates a QR code pointing to the surprise page. Print it or save it as an image/PDF. Keep `qr-card.html` private if you only want visitors to see the reveal page.

## Content settings

- Poster URL: edit the image `src` in `index.html`.
- TikTok product URL: edit the `href` on `.secret-link` in `index.html`.
- QR destination: pass the published URL through the `?url=` parameter on `qr-card.html`.

The QR image is generated by `api.qrserver.com`; the landing page itself has no build step and works directly on GitHub Pages.
